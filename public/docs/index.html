Reference

    
Send files as multipart/form-data (field file, options as fields) or as the raw body with options in the query string. Responses are the file itself, with a JSON summary in the X-AssetBench-Summary header and your quota in X-Quota-Remaining. Add ?output=json to get the full report with the file base64-encoded.

2 · Batch Asset Processing

        
POST /api/v1/batchoperation (any below) + that operation's options · files as several files fields or one ZIPZIP: results/<file>/… + manifest.json (JSON for audit). Up to 50 files per request.

        
3 · KTX2 Textures

        
POST /api/v1/textures/ktx2PNG/JPEG: mode etc1s|uastc · normalMap · linear · mipmaps · maxSize. GLB: mode auto (ETC1S colour, UASTC normals).ktx2, or a GLB with KHR_texture_basisu textures.

        
4 · 3D Asset Audit

        
POST /api/v1/3d/auditrole · target · engineJSON: size, triangles, draw calls, materials, texture memory, animation data, scored checks, and a score per device class. Free.

        
5 · 3D Format Conversion

        
POST /api/v1/3d/convertto glb|gltf|obj · scaleFBX / OBJ / glTF → GLB; GLB → glTF or OBJ (ZIPs). Send a ZIP when textures sit next to the model. FBX output is not offered.

        
6 · LOD Generation

        
POST /api/v1/3d/lodspreset standard|aggressive|minimal or levels "1,0.5,0.25" · compressZIP: lod0.glb… + report.json.

        
7 · iOS Asset Generation

        
POST /api/v1/ios/app-iconsplatforms ios,android,watchos · background · adaptiveScaleZIP: AppIcon.appiconset + Contents.json, Android mipmaps + adaptive icons, Play Store 512.

        
POST /api/v1/ios/xcassetsas app-icons, iOS by defaultZIP with the Xcode asset catalog.

        
POST /api/v1/ios/screenshots1–10 images (or a ZIP) · devices iphone-6.9,iphone-6.5,iphone-5.5,ipad-13,ipad-12.9,android-phone,android-tablet · fit cover|contain · background · format jpeg|pngZIP: one folder per device, sized exactly, opaque.

Errors

    
Errors are JSON: {"error":{"code":"quota_exhausted","message":"…"}}. Status codes: 400 bad option · 401 missing/invalid key · 403 engine not in plan · 413 file too large · 415 wrong file type (Draco-compressed GLBs can be audited but not processed yet) · 422 unreadable file · 429 quota used up.
