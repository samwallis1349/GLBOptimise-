AssetBench Cloud · API v1

Mobile-ready graphics, from your own code.

The same engines as the AssetBench tools, behind one API. Check a GLB against phone and headset budgets, cut it down to fit, build LOD chains, and turn one master image into every iOS, watchOS and Android icon. No GPU, no AI image generation: the processing is deterministic, so the same input always gives the same output.

Reference

    
Send files as multipart/form-data (field file, options as fields) or as the raw body with options in the query string. Responses are the file itself, with a JSON summary in the X-AssetBench-Summary header and your quota in X-Quota-Remaining. Add ?output=json to get the full report with the file base64-encoded.

Errors

    
Errors are JSON: {"error":{"code":"quota_exhausted","message":"…"}}. Status codes: 400 bad option · 401 missing/invalid key · 403 engine not in plan · 413 file too large · 415 wrong file type (including Draco-compressed GLBs, which can be inspected but not processed yet) · 422 unreadable file · 429 quota used up.
