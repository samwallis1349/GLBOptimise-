How it works

An API is a way for one program to ask another to do a job. You send a file, AssetBench does the work in the cloud, and you get the finished files back, usually in a few seconds.

1 Your fileA model (.glb, .fbx, .obj) or an icon (.png).
2 Send itFrom this page, one terminal command, or your own script.
3 We fix itFewer triangles, smaller textures, LODs, every icon size.
4 Use itA ZIP ready to drag into your engine or upload to the store.

Questions

    
What is an API, in plain English?
A way for programs to talk to each other. Instead of opening a website and clicking, your script (or this page) sends a file to an address like /api/v1/game-ready and gets the finished files back. The key is like a password that says the request is yours.

    
Do you keep my files?
No. Each file is processed in memory and sent straight back; nothing is saved on our side. We only count how many operations each key has used.

    
Which files can I send?
3D: GLB, glTF, OBJ and FBX (FBX and OBJ are converted to GLB first), including Draco- and Meshopt-compressed GLBs and models with WebP textures. Images: PNG, JPEG and WebP. Up to 25 MB per file on Free, 50 MB on All Access and 100 MB on Studio. You can upload files directly or pass a public url.

    
What counts as an operation?
One processed file. A game-ready pack, an icon set or a set of screenshots each count once, however many files come back. Checks are free and never count.

    
I already pay for All Access. Do I need anything else?
No. Your All Access licence key is also your API key, with 1,000 operations a month. Paste it into the key box below.

    
What happens if I run out?
Requests return a clear "quota used up" message until the month resets. Nothing is charged automatically; you can move to Studio for 5,000 a month.

Reference

    
Send files as multipart/form-data (field file, options as fields), as the raw body with options in the query string, or pass a remote file URL via ?url=https://… or JSON {"url":"https://…"}. Responses are the file itself, with a JSON summary in X-AssetBench-Summary and your quota in X-Quota-Remaining, X-Quota-Limit and X-Quota-Reset. Add ?output=json to get the full report with the file base64-encoded.
