# Project Guidelines & Memory

## Affiliate Programs
- **Tripo 3D**: The project owner is registered as an affiliate for Tripo 3D.
  - Configuration file: `src/shared/config/affiliates.js` (`TRIPO_AFFILIATE_URL`).
  - Partner touchpoints: Integrated into `src/shared/components/ToolNews.js` (partner card) and related promotional components.
  - Always use `TRIPO_AFFILIATE_URL` from `src/shared/config/affiliates.js` for any Tripo links.
